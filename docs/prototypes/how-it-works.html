How it worksComo funciona

The gameO jogo

Haru is on the gallows. The word shows as one blank per letter. Pick one letter at a time:

  • If the letter is in the word, it shows everywhere it appears.
  • If it isn't, one more piece of the gallows goes up. On the 7th miss the trapdoor opens.
  • Accents don't count: picking A also reveals Á, Â, Ã and À, and C reveals Ç.

Solo: a random word, with its category as a hint.

With a friend: one player picks the word and an optional hint, the other guesses. Roles swap every round and the room keeps the score.

O Haru está na forca. A palavra aparece com um espaço por letra. Escolha uma letra por vez:

  • Se a letra está na palavra, ela aparece em todas as posições.
  • Se não está, mais uma peça da forca é montada. No 7º erro o alçapão abre.
  • Acentos não contam: escolher A revela também Á, Â, Ã e À, e C revela Ç.

Solo: uma palavra sorteada, com a categoria como dica.

Com um amigo: um jogador escolhe a palavra e uma dica opcional, o outro adivinha. Os papéis trocam a cada rodada e a sala guarda o placar.

Peer-to-peer

In a game with a friend, the two browsers talk to each other directly. Haru's server only introduces them.

Numa partida com um amigo, os dois navegadores conversam direto. O servidor do Haru só apresenta um ao outro.

  1. Signaling. Each browser tells the server how it can be reached. The server passes this on to the other player. STUN helps each browser find its public address.
  2. Data channel. The browsers open a WebRTC channel between them and the moves go through it. If a network blocks the direct path, a TURN server relays the moves.
  1. Sinalização. Cada navegador conta ao servidor como pode ser encontrado, e o servidor repassa isso ao outro jogador. O STUN ajuda cada navegador a descobrir o próprio endereço público.
  2. Canal de dados. Os navegadores abrem um canal WebRTC entre eles e as jogadas passam por ali. Se uma rede bloqueia o caminho direto, um servidor TURN repassa as jogadas.

The server stores nothing. The room only exists in memory while it is open.

O servidor não guarda nada. A sala só existe na memória enquanto está aberta.
